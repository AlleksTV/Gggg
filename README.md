# Трекер нажатий клавиш

GUI-программа на Python (tkinter + pynput): считает, сколько раз нажата каждая клавиша за заданный период.

## Запуск
```
pip install -r requirements.txt
python key_tracker.py
```
На Linux нужен пакет `python3-tk` (например, `sudo apt install python3-tk`).

## Возможности
- **⚙ Настройки** — длительность периода (секунды / минуты / часы), автоматический запуск нового периода, игнорирование автоповтора при удержании клавиши. Настройки сохраняются в `settings.json`.
- **▶ Старт** — начинает период и обратный отсчёт; по истечении времени подсчёт останавливается.
- **■ Стоп** / **Сбросить** — остановка и обнуление счётчиков.
- Таблица клавиш отсортирована по количеству нажатий.
- Счётчики хранятся только в памяти — после перезапуска программы они всегда равны нулю.

## Примечания
- macOS: дайте терминалу/Python разрешение «Мониторинг ввода» (Системные настройки → Конфиденциальность).
- Linux: нужен X11 (в Wayland глобальный перехват клавиш ограничен).
