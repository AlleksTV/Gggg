# Счётчик клавиш

Считает нажатия каждой клавиши за заданное время.

```
pip install pynput
python key_tracker.py
```

Введите время в секундах и нажмите «Старт». Время сохраняется в `settings.json`, счётчики после перезапуска обнуляются.

# Секундомер

```
python stopwatch.py
```

Кнопка «Старт / Стоп» запускает и ставит на паузу, «Сброс» обнуляет.
